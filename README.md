# gulf-offshore-maps
Daily Gulf of America offshore maps for fishmaks.com.

Viewer: https://grinekb.github.io/gulf-offshore-maps/  
Images (fixed names, overwritten each morning): `live/<layer>_<zoom>.jpg`, `live/picks.png`, `live/status.json`.
Data: NOAA CoastWatch, JPL MUR, NOAA RTOFS. Experimental, not for navigation.
